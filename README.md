A make.fun bounty entry for **news-image-20261120**: sum up Friday 20 November 2026's world news in one image.

`main.py` draws a newspaper front page — masthead **THE WORLD TODAY**, a red date band, and six stories — with pure procedural PIL art. No network, fully deterministic: two runs write byte-identical PNGs.

## The six stories

1. **GTA VI smashes all records** — $3.79bn in a day, the biggest entertainment launch in history.
2. **Kyiv bridges hit in huge barrage** — 400+ drones and 110 missiles; two fall inside Poland.
3. **Trump, Xi and Putin pledge peace** — joint declaration after the first three-way Shenzhen summit.
4. **Myanmar rejects genocide ruling** — the junta calls it unfair, a day after the world court verdict.
5. **Climate talks stall in Antalya** — COP31 draft deadlocked over fossil-fuel wording.
6. **Anthropic slides 9% after record debut** — day-two dip after the $2tn debut; record $93.5bn IPO closes.

## Run it

```sh
python3 main.py   # writes /output/entry.png (1024x1024, <= 1 MiB)
```
